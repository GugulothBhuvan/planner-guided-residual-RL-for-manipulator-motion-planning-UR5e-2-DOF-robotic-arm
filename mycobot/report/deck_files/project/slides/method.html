Arm

integrated joint target, limited step per tick

E5, additive. The command is clip(base + α · residual). Authority is bounded by α times the step limit.

E5b, offset. The residual integrates an offset that persists, up to a limit, so it can leave the reference path.

Both residual designs were pre-registered. The additive one is the main recipe; the offset one is the second iteration after the additive result was understood.
